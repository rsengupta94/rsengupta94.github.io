{%- comment -%} Overrides the template shipped inside jekyll-redirect-from. The gem's own version adds alongside the redirect. That combination is ambiguous: Google documents that an *instant* meta refresh is interpreted as a permanent redirect, but publishes no precedence rule for a page that says "redirect me" and "don't index me" at once. The risk is that noindex wins, the old URL is dropped, and none of its ranking signal reaches the new page — the opposite of why the redirect exists. So this version keeps the three signals that all point the same way — rel=canonical, an instant meta refresh, and a JS location assignment — and omits noindex. Redirect stubs are still kept out of sitemap.xml, which the plugin handles by defaulting them to `sitemap: false`. GitHub Pages cannot send a real HTTP 301; this is the closest available. {%- endcomment -%} {%- comment -%} replace() rather than assignment so the dead URL does not land in the visitor's back-button history. jsonify supplies the quotes and escaping. {%- endcomment -%}
